# 元分析（Meta-Analysis）

## 何时使用本技能

元分析是对同一主题的多项独立研究进行**系统检索、质量评价与定量合并**的统计方法。当出现以下情形时使用：

- 同一问题已有 **≥ 5–10 项**可比较的实证研究，结论不一致或效应方向不明；
- 需要估计效应量的**总体平均大小**（如干预效果 d ≈ 0.5）；
- 需要检验结果差异的来源（亚组、调节变量）；
- 需要评估文献的**发表偏倚**（阴性结果是否被压稿）。

**不适用**：研究数量太少（< 3–5 项）、研究设计差异过大无法合并、或只是文献综述（无定量合并）。

## 标准工作流程（PRISMA 规范）

### 第 1 步：注册与制定方案

- 在 **PROSPERO** 注册方案，写明 PICOS：P 人群、I 干预/暴露、C 对照、O 结局、S 研究设计；
- 明确纳入/排除标准（语言、年份、研究类型、人群、效应量类型）；
- 预先声明分析方法（固定/随机、亚组计划、敏感性分析）。

### 第 2 步：系统检索

- 数据库：PubMed / Embase / Web of Science / Cochrane / CNKI / 万方（中文研究必检）；
- 检索式：主题词（MeSH）+ 自由词，用 AND/OR/NOT 组合；至少两人独立检索核对；
- 补充：手工检索参考文献（snowballing）、联系作者索取未发表数据、检索灰色文献（Google Scholar、预印本）。

### 第 3 步：筛选与数据提取

- 两轮筛选：先读标题摘要（排除明显无关），再读全文（按纳入标准判定）；
- 双人独立筛选，不一致由第三人仲裁；报告 Kappa 一致性；
- 提取：作者年份、样本量、效应量及方差/CI、研究设计、质量评分、亚组信息。

### 第 4 步：质量评价

- 随机对照试验：Cochrane Risk of Bias 2（RoB 2）；
- 观察性研究：NOS（Newcastle-Ottawa Scale）或 ROBINS-I；
- 横断/准实验：各自适用的工具（如 JBI 清单）。

## 效应量类型与转换

| 效应量 | 适用 | 公式要点 |
| --- | --- | --- |
| Cohen's d | 两组均值比较 | d = (M₁ − M₂) / S_pooled |
| Hedges' g | 小样本校正后的 d | g = d × (1 − 3/(4N − 9)) |
| r | 相关研究 | 合并前转 Fisher's z |
| OR | 病例对照/二元结局 | 取 log(OR) 合并 |
| RR | 队列/RCT 二元结局 | 取 log(RR) 合并 |

关键公式：

```text
Cohen's d = (M1 - M2) / Sp
Sp = sqrt(((n1-1)*S1^2 + (n2-1)*S2^2) / (n1+n2-2))
SE(d) = sqrt((n1+n2)/(n1*n2) + d^2/(2*(n1+n2)))
Hedges' g = d * (1 - 3/(4*(n1+n2) - 9))

Fisher's z = 0.5 * ln((1+r)/(1-r))
SE(z) = 1/sqrt(n - 3)

log(OR) 的 SE = sqrt(1/a + 1/b + 1/c + 1/d)   # a,b,c,d 为四格表频数
log(RR) 的 SE = sqrt(1/a - 1/(a+b) + 1/c - 1/(c+d))
```

- 从 t 值还原 d（两组等 n 时）：d = 2t / sqrt(df)；
- 只有中位数/四分位数的研究：用 Wan et al. (2014) 公式估算均值与 SD，或在敏感性分析中剔除；
- 零事件研究：加 0.5 连续性校正，或使用 Peto OR / Mantel-Haenszel 法（RCT 小样本首选）。

## 固定效应 vs 随机效应（决策标准）

| 判断依据 | 固定效应 (FE) | 随机效应 (RE) |
| --- | --- | --- |
| 研究间异质性 | 可忽略（I² 低、Q 不显著） | 存在（I² 中高、Q 显著） |
| 推断目标 | 仅这些研究的平均效应 | 推广到研究总体 |
| 权重逻辑 | 按精度（n）加权 | 按 1/(方差 + τ²) 加权 |
| 结论含义 | 共同真实效应 | 效应分布的平均值 |
| CI 宽度 | 通常较窄 | 一般更宽、更保守 |

**实操决策顺序**：
1. 先看 Q 检验（p < 0.10 即认为异质性显著）与 I²（< 25% 低、25–50% 中、> 50% 高）；
2. 若 I² ≥ 50% 或 Q 显著 → 随机效应；
3. 若研究间临床/方法学差异大（即使 I² 低）→ 仍建议随机效应作为主分析；
4. 预先指定主分析方法，两种都跑作为敏感性分析亦可。

## 异质性指标与公式

```text
Q = Σ wi * (yi - ȳ)^2          # Cochran's Q，服从 χ²(k-1)
I² = max(0, (Q - df) / Q * 100%)
τ² = 研究间方差（DerSimonian-Laird 或 REML 估计）
```

- I² 是**总变异中由研究间差异贡献的比例**，不是绝对异质性大小，且受研究数量影响；
- 报告 τ² 与**预测区间**（prediction interval），预测区间反映未来研究效应可能落在哪里；
- 异质性大时优先做亚组/元回归解释来源，而非直接放弃合并。

## R metafor 工作流程

```r
library(metafor)

# 1) 从效应量 + 标准误合并（以 Hedges' g 为例）
dat <- data.frame(
  study = c("Li2020", "Wang2021", "Chen2022"),
  gi    = c(0.52, 0.31, 0.78),   # Hedges' g
  sei   = c(0.18, 0.15, 0.22)    # 标准误
)

# 固定效应
res_fe <- rma(yi = gi, sei = sei, data = dat, method = "FE")
# 随机效应（REML 估计 τ²，推荐）
res_re <- rma(yi = gi, sei = sei, data = dat, method = "REML")
summary(res_re)   # estimate、CI、I²、H²、QE、tau²

# 2) 森林图（OR/RR 用 transf = exp 转换回原始尺度）
forest(res_re, slab = dat$study, transf = exp)

# 3) 发表偏倚：漏斗图 + Egger 检验 + 剪补法
funnel(res_re)
regtest(res_re)      # Egger 回归检验（p < 0.10 提示偏倚）
trimfill(res_re)     # 剪补法，校正后的合并效应

# 4) 亚组分析（QM 检验亚组间差异）
res_sub <- rma(yi = gi, sei = sei, data = dat, mods = ~ subgroup)
summary(res_sub)

# 5) 元回归（连续调节变量）
res_meta <- rma(yi = gi, sei = sei, data = dat, mods = ~ age + year)
summary(res_meta)

# 6) 从原始数据计算效应量
es <- escalc(measure = "SMD", m1i = m1, sd1i = sd1, n1i = n1,
             m2i = m2, sd2i = sd2, n2i = n2, data = raw)
# 其他 measure："OR"、"RR"、"COR"（r 自动转 Fisher's z）、"ZCOR"
```

## 发表偏倚评估

| 方法 | 用途 | 判断 |
| --- | --- | --- |
| 漏斗图 (funnel plot) | 目视对称性 | 不对称 → 潜在偏倚 |
| Egger 检验 | 小样本效应回归 | p < 0.10 提示偏倚 |
| Begg 检验 | 秩相关法 | 较 Egger 弱 |
| Trim-and-fill | 校正偏倚 | 报告校正前后效应 |
| Fail-safe N | 需多少阴性研究推翻结论 | 仅作参考，逐渐少用 |
| p-curve / 选角分析 | 检验 p-hacking | 进阶可选 |

注意：Egger 检验在 **k < 10** 时功效很低，漏斗图也难解读；漏斗图不对称 ≠ 必然存在发表偏倚，需结合检索完整性与异质性讨论。

## 亚组与元回归的决策

- 亚组变量：研究设计（RCT vs 准实验）、人群特征（年龄、性别）、干预类型、质量等级、地区；
- 亚组分析 = 分类调节变量；元回归 = 连续调节变量（也可对分类变量编码）；
- 亚组内 k < 3 时结果不可靠；亚组间差异看 QM 检验而非仅看单个亚组是否显著；
- 避免对同一数据反复做大量亚组/元回归（多重比较膨胀）；应预先注册分析计划。

## 敏感性分析

- 剔除质量低（高风险偏倚）的研究；
- 逐个剔除（leave-one-out）检验单一研究的影响；
- 更换效应量模型（RE↔FE）、更换 τ² 估计法（DL vs REML）；
- 剔除异常值（极端效应量或权重过大的研究）后结论是否稳健；
- 用不同统计量（如用 RR 代替 OR）重跑。

## SPSS / 其他工具要点

- SPSS 无原生元分析模块，常用 David Wilson 的宏（MeanES / MetaF / MetaReg）或 Jamovi + MAJOR 模块；复杂分析建议直接用 R metafor；
- 森林图、漏斗图可用 R 绘制后嵌入论文；中文论文常需附 PRISMA 流程图（可用 PRISMA 官网流程图生成器）。

## 常见误区

| 误区 | 后果 | 正确做法 |
| --- | --- | --- |
| 只检索一个数据库 | 漏检，引入偏倚 | 多库 + 灰色文献 + 引文追溯 |
| 重复纳入同一样本的多个发表 | 数据重复加权 | 核对样本，去重 |
| 异质性高还用固定效应 | CI 过窄、结论误导 | 随机效应 + 解释异质性 |
| I² 高就直接放弃合并 | 丢失信息 | 亚组/元回归寻找来源 |
| Egger p > 0.05 就断言无偏倚 | 假阴性（小 k 时） | 结合漏斗图与检索完整性 |
| 零事件研究直接丢弃 | 丢失信息、OR 偏倚 | 0.5 校正或 Peto/MH 法 |
| 数据提取单人不核对 | 错误传导到合并结果 | 双人提取 + 交叉核对 |
