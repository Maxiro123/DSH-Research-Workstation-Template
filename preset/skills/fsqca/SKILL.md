# fsqca

## 一、何时使用 fsQCA

fsQCA（模糊集定性比较分析，fuzzy-set Qualitative Comparative Analysis）用于回答"哪些条件**组合**（组态）与结果构成集合关系"的问题。其核心主张是**多重并发因果**（conjunctural causation）与**等效路径**（equifinality）：多种不同的条件组合都能导致同一结果，且"导致结果"与"阻止结果"的路径不一定互为镜像（**非对称因果**）。

当以下特征占多数时，优先考虑 fsQCA 而非回归：

| 维度 | 回归（如 OLS/Logit） | fsQCA |
|---|---|---|
| 因果关系观 | 变量的净效应、对称因果 | 组态效应、非对称因果 |
| 样本量 | 大样本（一般 >100 起） | 中样本（10–100）更合适 |
| 数据基础 | 方差-协方差、线性可加 | 集合隶属、布尔代数 |
| 结果形式 | 回归系数、显著性 | 充分/必要条件组合（A*B + C*~D） |
| 案例取向 | 变量导向 | 案例导向（可回溯到具体案例） |
| 处理"异常案例" | 残差 | 反事实与组态解释 |
| 等效路径 | 不支持 | 核心能力 |

**何时不用 fsQCA**：纯大样本效应估计；需要控制混杂的因果推断（改用匹配、工具变量等）；变量关系本质上是线性且对称的；样本极小（<10）且无法论证案例完整性；研究者只需要"某个变量是否显著"。

## 二、核心概念速查

| 概念 | 含义 | 记法 |
|---|---|---|
| 集合（set） | 条件/结果的概念化，成员度 ∈ [0,1] | X, Y |
| 隶属度 | 案例在集合中的程度 | x_i, y_i |
| 清晰集（crisp） | 二值 {0,1} | csQCA |
| 模糊集（fuzzy） | 连续 [0,1]，0.5 为交叉点 | fsQCA |
| 否定（negation） | 非 X | ~X 或 ¬X |
| 逻辑与（交集） | 条件并存 | A*B |
| 逻辑或（并集） | 条件至少其一 | A + B |
| 组态（configuration） | 条件的特定组合 | A*B*~C |
| 真值表行 | 每种组态对应一行 | 共 2^k 行 |
| 有限多样性 | 数据未覆盖的组态（remainder） | —— |
| 一致性（consistency） | 集合关系的成立程度 | incl |
| 覆盖度（coverage） | 集合关系的实证相关性 | cov |

## 三、标准分析流程（七步）

1. **研究设计与条件选择**：明确结果 Y 与条件集 {A, B, C, …}。条件来自理论对话而非穷举；同时必须规划分析结果的否定 ~Y（非对称性要求）。
2. **案例选择**：案例须在结果与条件上都有变异；典型 10–100 个；先界定案例边界（population）。
3. **数据校准**：把原始数据转换为集合隶属度（见第四节）。这是 fsQCA 最"主观"也最关键的一步。
4. **必要性分析**：逐一检验每个条件（含其否定）是否为结果的必要条件。
5. **构建真值表**：设定频数门槛（n.cut）与一致性门槛（incl.cut、PRI），剔除不可靠行。
6. **充分性分析（布尔最小化）**：分别求复杂解、简约解、中间解。
7. **解读与稳健性检验**：以中间解为主做实质解读，标注核心/边缘条件，做敏感性分析并报告。

## 四、校准（Calibration）

校准把"程度"信息映射为隶属度，常用**直接法**（Ragin 2008，logit 变换）与**间接法**。

三个定性锚点：

| 锚点 | 隶属度 | 含义 |
|---|---|---|
| 完全隶属 | 0.95（或 1.0） | 确定属于该集合 |
| 交叉点 | 0.5 | 隶属/不隶属的分界 |
| 完全不隶属 | 0.05（或 0.0） | 确定不属于该集合 |

直接法思路：先把原始值映射到 log-odds 尺度（"案例隶属于集合的对数几率"），再反变换为 0–1 隶属度；软件完成计算，研究者只需给出锚点值。

```r
library(QCA)
# 模糊集直接法：锚点取原始分布的第 5、50、95 百分位
dat$Y_cal <- calibrate(dat$Y_raw, type = "fuzzy", method = "direct",
                       thresholds = c(5, 50, 95))
# 或按理论定性锚点（如 1–7 量表的切点）
dat$A_cal <- calibrate(dat$A_raw, type = "fuzzy", method = "direct",
                       thresholds = c(2, 4, 6))
# 清晰集（csQCA）
dat$B_crisp <- calibrate(dat$B_raw, type = "crisp", thresholds = 3)
```

**校准要点**：
- 锚点必须有实质依据（理论、量表规范、案例知识），并在论文中透明报告；不要用均值±标准差这类"统计默认"掩盖定性判断。
- 检查是否有案例隶属度恰好为 0.5：它们无法被归入真值表的"在/不在"一侧，应调整锚点或说明处理方式。
- 校准后检查变异：如果所有案例都落在 [0.9, 1]，该条件没有区分力，应重新界定或删除。

## 五、必要性分析

必要条件 = 结果成立时该条件必然成立，即 Y 是 X 的子集（Y ≤ X）。

- 必要性一致性：`ConsN = Σ min(y_i, x_i) / Σ y_i`
- 必要性覆盖度：`CovN = Σ min(y_i, x_i) / Σ x_i`

```r
nec <- necessity(dat, outcome = "Y", conditions = c("A","B","C","~A","~B","~C"))
print(nec)
# 等价写法：pof(dat$A_cal, outcome = dat$Y_cal, relation = "necessity")
```

**判断标准**：
- 一致性 ≥ 0.90（严谨文献建议 ≥ 0.95）才可声称"几乎总是必要条件"；0.8–0.9 只能作为弱证据。
- 高一致性但低覆盖度 = **平凡必要条件**（几乎所有案例都具备该条件，解释力弱）；务必报告覆盖度判断实质意义。
- 同时检验条件与其否定：若两者都"必要"则出现逻辑矛盾，说明条件设定或校准有问题，须回头修正。

## 六、真值表与充分性分析

充分条件 = 条件组合成立时结果必然成立，即 X ≤ Y。

- 充分性一致性：`ConsS = Σ min(x_i, y_i) / Σ x_i`
- 充分性覆盖度：`CovS = Σ min(x_i, y_i) / Σ y_i`
- PRI（不一致性比例缩减）：衡量组态对结果 Y 而非其否定 ~Y 的独特一致性：
  `PRI = Σ [min(x_i, y_i) − min(x_i, y_i, ¬y_i)] / Σ [x_i − min(x_i, y_i, ¬y_i)]`

```r
tt <- truthTable(dat, outcome = "Y",
                 conditions = c("A","B","C"),
                 n.cut = 1,        # 频数门槛：行内最少案例数
                 incl.cut = 0.80,  # 充分性一致性门槛
                 PRI = 0.70,       # PRI 门槛
                 show.cases = TRUE)
tt
# 逐行检查：n（案例数）、incl（一致性）、PRI、cases（案例名单）
```

**门槛设置经验**：
- n.cut：小样本（≤40）通常为 1；大样本可提高到 2–3 以剔除偶发组态。
- incl.cut：常用 0.80；Schneider & Wagemann（2012）建议最低 0.75 且须论证；若一致性普遍偏低，先反思条件选择与校准，而非无限制下调门槛。
- PRI ≥ 0.70–0.75：某行一致性高但 PRI 低，说明该组态同时是结果与否定结果的子集（矛盾组态），应排除或重新编码。

## 七、三种解与反事实

布尔最小化会利用"反事实"（数据中不存在的组态，即 remainder）：

| 解 | 反事实使用 | 特征 | 用途 |
|---|---|---|---|
| 复杂解 | 不用任何反事实 | 最保守、通常最繁琐 | 完全经验基础 |
| 简约解 | 使用全部反事实 | 最精简 | 识别核心条件（与中间解比较） |
| 中间解 | 仅用符合方向性预期的反事实 | 理论+经验平衡 | **主报告对象** |

```r
# 复杂解
sol_c <- minimize(tt, include = "?")
# 简约解
sol_p <- minimize(tt, include = "*")
# 中间解：必须给出方向性预期 dir.exp（1=存在促进结果，0=不存在促进，-1=不预设）
sol_i <- minimize(tt, include = "C", dir.exp = c(1, 0, 1))
sol_i
```

**核心 vs 边缘条件**：出现在简约解（且中间解）中的条件为核心条件；仅出现在中间解中的为边缘条件。

**反事实纪律**：只允许与理论方向预期一致、且不与经验证据相悖的反事实进入中间解（Schneider & Wagemann 的"增强标准分析"）。无依据的"简化假设"是简约解被批评的主因。

## 八、关键阈值速查表

| 指标 | 常用阈值 | 说明 |
|---|---|---|
| 必要性一致性 | ≥ 0.90（严谨 ≥ 0.95） | 低于此不称"必要条件" |
| 必要性覆盖度 | 越高越好，>0.5 可接受 | 低覆盖 = 平凡必要 |
| 充分性一致性 incl.cut | ≥ 0.75–0.80（常用 0.80） | 真值表行纳入门槛 |
| PRI | ≥ 0.70–0.75 | 防矛盾组态（同时子集） |
| n.cut | 1（小样本）；大样本 2–3 | 行内最少案例数 |
| 解的覆盖度 | ≥ 0.50 较理想 | 解解释了多少结果隶属变异 |
| 单条路径覆盖度 | 报告原值即可 | 区分主要/次要路径 |
| 条件个数 k | N≈10–40 时 k≤4–5；N≈60–100 时 k≤6–7 | 防有限多样性失控 |

## 九、R 完整工作流（QCA 包）

```r
library(QCA)
# 1. 校准（见第四节）
# 2. 必要性
nec <- necessity(dat, outcome = "Y", conditions = c("A","B","C","~A","~B","~C"))
print(nec)
# 3. 真值表
tt <- truthTable(dat, outcome = "Y", conditions = c("A","B","C"),
                 n.cut = 1, incl.cut = 0.8, PRI = 0.7, show.cases = TRUE)
# 4. 三种解
sol_i <- minimize(tt, include = "C", dir.exp = c(1, 0, 1))
sol_p <- minimize(tt, include = "*")
# 5. 结果对象
sol_i$solution        # 路径公式
sol_i$IC              # 各路径与整体的一致性/覆盖度
# 6. XY 散点图（SetMethods 包）
library(SetMethods)
pimplot(dat, results = sol_i, outcome = "Y")
# 7. 稳健性检验：变换锚点/门槛重跑
dat2 <- dat
dat2$Y_cal <- calibrate(dat$Y_raw, thresholds = c(10, 50, 90))
tt2 <- truthTable(dat2, outcome = "Y", conditions = c("A","B","C"),
                  n.cut = 1, incl.cut = 0.75, PRI = 0.65)
sol_i2 <- minimize(tt2, include = "C", dir.exp = c(1, 0, 1))
```

**QCA 包关键函数**：`calibrate`（校准）、`truthTable`（真值表）、`minimize`（最小化）、`necessity`/`sufficiency`/`pof`（拟合参数）、`XYplot`（XY 图）。补充包 `SetMethods` 提供 `QCAfit`、`pimdata`、`pimplot` 等稳健性与可视化工具；`QCApro` 支持更复杂组态。

## 十、fsQCA 桌面软件工作流（Ragin & Davey）

1. **数据**：CSV 导入，一行一个案例，列为条件与结果的原始值。
2. **校准**：菜单 *Variables & Sets → Compute → Calibrate*，填入三个锚点，生成模糊集变量。
3. **真值表**：*Analyze → Truth Table Algorithm*，选择结果与条件，设定 *Consistency Cutoff*（0.8）与 *Frequency Cutoff*（1）。
4. **标准分析**：*Analyze → Standard Analysis*，勾选方向性预期，得到复杂/简约/中间解。
5. **输出**：报告各路径一致性、覆盖度与所属案例。

> 桌面软件 fs/QCA 与 R 的 QCA 包结果应一致；若不一致，优先检查校准定义与门槛设置是否相同。

## 十一、常见误区与陷阱

| 误区 | 正确做法 |
|---|---|
| 把 QCA 当"小样本回归"，把路径解读为变量效应 | 解读为**组态**：A*B 一起构成充分条件 |
| 只分析结果 Y，忽略 ~Y | 非对称因果要求同时分析 Y 与 ~Y |
| 校准锚点拍脑袋或用均值 | 锚点须有理论/实质依据并透明报告 |
| 只做充分性、跳过必要性 | 两步都做；必要性结果是论文独立板块 |
| 忽视 PRI，出现矛盾组态 | 检查 PRI，剔除同时子集行 |
| 中间解不给方向性预期 | 中间解必须由方向性预期定义 |
| 条件过多（2^k 远超 N） | 精简条件；报告有限多样性程度 |
| 把简约解当主结果 | 主报告中间解，简约解用于识别核心条件 |
| 不做稳健性检验 | 变换锚点/门槛/案例集重跑并汇报一致性 |
| 用 QCA 论证时序因果 | QCA 是组态快照，因果时序需案例内证据支撑 |
| 案例数 <10 仍强行运行 | 论证案例完整性，或改用深度案例研究 |
