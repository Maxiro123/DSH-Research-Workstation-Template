# item-response-theory

## 一、何时使用 IRT

项目反应理论（Item Response Theory, IRT）把"能力/特质 θ"与"作答反应"的关系建模为概率函数，提供**题目层面**的测量信息。适合使用的情形：
- 开发或修订测验/量表，需要逐题评价（难度、区分度、猜测参数、信息量）；
- 需要**题库建设**、计算机化自适应测验（CAT）或分数可比性（等值）支撑；
- 需要检验**项目功能差异（DIF）**——同一题目对不同群体（性别、文化）是否测量同构念；
- 需要精确的测量标准误（每个能力水平的精度不同）；
- 数据为二值（0/1 计分）或多级计分（李克特、评定量表）的测验/量表。

不适合的情形：
- 样本量小（见下）且无题库/等值需求——经典测量理论（CTT）足够；
- 只关心总分信度与相关（α 即可）；
- 单题测量或非标准化的探索性量表。

**CTT vs IRT 关键区别**：

| 维度 | CTT（经典测量理论） | IRT |
|---|---|---|
| 基本单元 | 总分与误差 | 题目反应概率模型 |
| 题目参数 | 难度=得分率 p，区分度=题总相关 | a（区分度）、b（难度）、c（猜测） |
| 参数不变性 | 依赖样本/测验 | 理论上不依赖样本与测验 |
| 测量精度 | 全域单一标准误 | 逐能力水平的信息函数 |
| 分数可比 | 跨测验困难 | 支持等值与 CAT |
| 前提 | 误差随机 | 单维性、局部独立、单调性等 |
| 样本要求 | 较低 | 较高（尤其 2PL/3PL） |

## 二、模型体系与公式

θ 为潜在特质（通常标准化，均值 0、方差 1），P_i(θ) 为第 i 题答对概率：

- **1PL（Rasch 模型）**：`P_i(θ) = exp(θ − b_i) / [1 + exp(θ − b_i)]` —— 仅难度不同，区分度全等。
- **2PL**：`P_i(θ) = exp[a_i(θ − b_i)] / [1 + exp[a_i(θ − b_i)]]` —— 允许区分度不同。
- **3PL**：`P_i(θ) = c_i + (1 − c_i) · exp[a_i(θ − b_i)] / [1 + exp[a_i(θ − b_i)]]` —— 增加猜测参数 c。
- **多级计分**：等级反应模型（GRM）：`P(X ≥ k | θ) = exp[a(θ − b_k)] / [1 + exp[a(θ − b_k)]]`；广义分部评分模型（GPCM）与分部评分模型（PCM，Rasch 类）用于"部分正确"或评定量表。

**项目特征曲线（ICC）**：P_i(θ) 对 θ 的 S 形曲线。2PL 下拐点位于 θ = b（答对概率 0.5），拐点斜率 = a/4；a 越大曲线越陡、区分能力越强；3PL 下曲线下渐近线为 c。

**信息函数**：2PL 单项信息 `I_i(θ) = a_i² · P_i(θ) · (1 − P_i(θ))`；测验信息 `I(θ) = Σ I_i(θ)`；测量标准误 `SE(θ) = 1 / √I(θ)`。信息量在 b 附近最大，随 a 增大而增大。

## 三、参数解读与常用阈值

| 参数 | 含义 | 参考范围/阈值 |
|---|---|---|
| b（难度） | 答对概率 0.5 处的能力水平 | 通常 −3 ~ +3；b=0 为中等难度；越大越难 |
| a（区分度） | ICC 的陡峭程度 | Baker 分类：<0.34 很低、0.35–0.64 低、0.65–1.34 中等、1.35–1.69 高、≥1.7 很高；**a<0.5 通常需修改或删除题目** |
| c（猜测） | 低能力者猜对概率 | 基线=1/选项数（四选一为 0.25）；常见 0.05–0.3；**c>0.35 提示干扰项设计有问题** |

注意：不要把 b 与原始得分率 p 混淆（b 是 logit 尺度且与样本无关）；3PL 的 c 不等于"正确率"。

## 四、模型假设与检验

1. **单维性**：测验只测一个潜在特质——用探索性因子分析/平行分析（第一因子解释力、残差结构）检查。
2. **局部独立性**：控制 θ 后题目残差互不相关——用标准化残差相关（Yen 的 **Q3**，|Q3|>0.2 提示局部依赖）检查；题组（testlet）会系统违反，需用题组模型（如 mirt 的 `itemtype="testlet"` 或 bifactor 模型）。
3. **单调性**：答对概率随 θ 单调上升——用 Mokken 分析或 ICC 检查。
4. **模型-数据拟合**：整体与题目层面同时检验（见下）。

## 五、模型选择与拟合评价

- **整体拟合**：M2 统计量及衍生指标——RMSEA ≤ 0.06（可放宽 ≤0.08）、CFI/TLI ≥ 0.95（0.90 可接受）、SRMR ≤ 0.08。
- **题目拟合**：S-X²（Orlando & Thissen）与 G²；Rasch 类用 **infit/outfit**（均方）——0.5–1.5 可接受，理想 0.7–1.3；>1.5 表示题目"不拟合"（噪声大），<0.5 表示过度拟合（冗余）。
- **模型比较**：嵌套模型用似然比检验与 AIC/BIC（如 1PL vs 2PL vs 3PL）。
- **参数估计方法**：能力用 MLE / MAP / EAP；项目参数用边际极大似然-EM（MMLE/EM，如 mirt 默认）、Rasch 的联合估计（JMLE）。
- **样本量经验**：1PL ≥ 200–300；2PL ≥ 500；3PL ≥ 1000；DIF 分析每组 ≥ 200–500。

## 六、DIF 分析（项目功能差异）

DIF = 控制能力后，不同群体（参照组/焦点组）在同一题上的作答概率仍不同——提示题目存在测量偏差。

- **类型**：均匀 DIF（仅难度 b 不同）；非均匀 DIF（区分度 a 也/仅不同）。
- **常用方法**：Mantel-Haenszel（MH）、Logistic 回归（difR::difLogistic）、IRT 似然比（lordif）。
- **规模判据**：Zumbo（1999）——ΔR²（McFadden）<0.035 可忽略、0.035–0.07 中等、>0.07 大；lordif 默认以 **ΔR²=0.02** 为入选阈值，结果要同时报显著性（卡方）与效应量，避免"样本大则一切显著"。
- **处理**：检出大 DIF 的题目应审查题目内容（翻译、文化、内容偏向），必要时删除或保留但计分时剔除（purification）。

```r
library(lordif)
out <- lordif(data, group, criterion = "Chisqr", alpha = 0.01)
summary(out)          # 各题 DIF 统计量、ΔR²、决策
plot(out)             # 分组的 ICC 对比
```

## 七、测验等值（Equating）

目标：把不同测验版本（A/B 卷、前后测）的分数放到同一能力量表上。

- **设计**：等效组设计（随机分组各做一卷）、单组设计（同一组做两卷）、**锚题非等效组设计**（两卷含共同锚题，最常用）。
- **参数等值法**：mean/mean、mean/sigma（线性变换）；**Stocking-Lord**、**Haebara**（基于信息函数的特征曲线法，更稳健）。
- **能力尺度变换**：`θ* = A·θ + B`，把 B 卷能力映射到 A 卷量表。
- **同时标定（concurrent calibration）**：两卷数据放一起联合估计，锚题参数共享。
- **检验**：锚题参数跨版本不变性、等值标准误（SEED）、等值前后分布比较。

## 八、R 完整工作流（mirt / ltm / lordif）

```r
library(mirt)
# 数据：0/1（或多级计分）矩阵，行=被试，列=题目
# 1. 模型拟合与选择
m1 <- mirt(data, 1, itemtype = "Rasch")   # 1PL
m2 <- mirt(data, 1, itemtype = "2PL")     # 2PL
m3 <- mirt(data, 1, itemtype = "3PL")     # 3PL
mg <- mirt(data, 1, itemtype = "graded")  # 多级（GRM）
anova(m1, m2, m3)                         # 似然比 + AIC/BIC
# 2. 整体拟合
M2(m2)                                    # RMSEA/CFI/TLI/SRMR
# 3. 项目参数（IRT 参数化，含 SE）
coef(m2, IRTpars = TRUE, simplify = TRUE)
# 4. 信息函数与标准误
plot(m2, type = "info")                   # TIF
th <- seq(-4, 4, by = 0.1)
SE <- 1 / sqrt(testinfo(m2, th))
# 5. 能力估计
fs <- fscores(m2, method = "EAP")
# 6. 题目拟合与局部依赖
itemfit(m2)                               # S-X²
residuals(m2, type = "Q3")                # Q3 相关矩阵
```

```r
# ltm 包（教学与快速比较）
library(ltm)
f1 <- rasch(data); f2 <- ltm(data ~ z1); f3 <- tpm(data)
anova(f1, f2, f3)
# DIF（Logistic 回归）
library(difR)
res <- difLogistic(data, group, focal.name = "F", type = "both")
```

等值（锚题设计）可用 `equateIRT` 包（分别估计后变换）或 mirt 的同时标定（合并数据 + `group=` 指定表单、锚题 `invariance=` 约束）；CAT 用 `mirtCAT` 包。

## 九、常见误区与陷阱

| 误区 | 正确做法 |
|---|---|
| 样本量不足仍拟合 2PL/3PL | 按模型选择样本量；小样本用 1PL/Rasch |
| 不检验单维性与局部独立 | 先做因子分析/平行分析与 Q3 检查 |
| 把 3PL 的 c 当"正确率" | c 是低能力者猜对概率，检查干扰项质量 |
| 混淆难度 b 与原始得分率 | b 是 logit 尺度、样本无关参数 |
| DIF 只报显著性不报效应量 | 同时报 ΔR² 等效应量，避免大样本假阳性 |
| 等值锚题本身有 DIF | 等值前先检验锚题 DIF 并剔除 |
| 不报告模型-数据拟合 | 整体（RMSEA/CFI）与题目（S-X²/infit）都要报 |
| 把 θ 直接当原始分数汇报 | 向非专业读者解释 θ 量表含义或转换为量表分 |
| 多级计分选错模型 | GRM/GPCM/PCM 适用条件不同（评定量表 vs 部分正确） |
| 忽略题组导致的局部依赖 | 用题组/双因子模型处理 |
| 只报 Cronbach's α 不报信息函数 | IRT 下报告 TIF 与逐水平 SE |
