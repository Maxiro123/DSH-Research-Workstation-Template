# paper-writing

> 学术论文写作（Academic Paper Writing）——从标题到参考文献、从图表到审稿回复，帮助 AI 代理协助研究者产出符合期刊规范、可复现、经得起审稿的论文。

## 何时使用本技能

- 研究者准备撰写或修改一篇学术论文/学位论文。
- 需要规范引用格式（APA 7、MLA 9、Chicago、GB/T 7714）。
- 需要制作符合出版规范的结果图表。
- 需要选择投稿期刊或评估期刊质量。
- 需要撰写 Response to Reviewers 或修改稿件。

## 核心原则

1. **读者第一**：审稿人一天读几十篇稿件，结构清晰、信息前置是最大优势。
2. **先骨架后血肉**：先写结果与图表 → 方法 → 引言 → 讨论，摘要与标题最后写。
3. **每个句子都有证据**：方法可复现、结果可核对、讨论不越界。
4. **诚实是最高要求**：不夸大、不隐藏负面结果、不"美化"统计。

## IMRaD 结构总览

| 部分 | 作用 | 建议篇幅（正文占比） |
|------|------|--------------------|
| Introduction 引言 | 背景 → 缺口 → 本研究目的 | 15–20% |
| Methods 方法 | 可复现的操作细节 | 20–25% |
| Results 结果 | 客观陈述发现（不含解释） | 25–30% |
| Discussion 讨论 | 解释、比较、局限、结论 | 25–30% |

写作顺序建议：Results → Methods → Introduction → Discussion → 摘要/标题。方法部分在实验结束时就应写，趁细节未忘。

## 标题（Title）

- 要求：具体、简洁、信息完整；通常 10–20 词；含关键概念词（利于检索）。
- 类型：
  - **描述性**："抗阻训练对老年 2 型糖尿病患者糖化血红蛋白的影响"（中立、常用）。
  - **结论性**："每周两次抗阻训练显著改善老年 2 型糖尿病患者的血糖控制"（含结果，注意勿夸大）。
- 避免：缩写、冗长从句、"A study of…"式空话、幽默或双关。
- 中文期刊：一般 ≤ 20 字；英文：≤ 15–20 词；两者均需提供（若期刊要求）。

## 摘要与关键词

### 摘要（Abstract）
- 结构式摘要（医学/心理期刊普遍要求）：**目的 → 方法 → 结果 → 结论**，各 1–2 句。
- 字数：英文 150–250 词；中文 200–300 字。
- 要点：结果段给出**关键数字**（如 "M = 78.4 vs 70.1, p = .002, d = 0.84"）；结论不超出现有证据；不得出现正文没有的内容或参考文献。
- 先写正文，最后写摘要；写完与正文逐项核对。

### 关键词（Keywords）
- 3–6 个；优先使用领域标准词表（医学用 MeSH，心理用 APA Thesaurus）。
- 顺序：核心主题词在前，方法词在后。

## 引言（Introduction）

漏斗结构，通常 3–5 段：
1. 研究领域背景与重要性（"为什么这个领域值得研究"）。
2. 已有研究进展与共识（引用关键文献，不是文献综述堆砌）。
3. **研究缺口**（gap）：现有证据的矛盾/空白/方法局限——这是引言灵魂，用"然而/尽管…尚未…"句型明确点出。
4. 本研究目的与研究问题/假设。
5. 研究意义与（可选）主要贡献预览。

常见错误：引言写成文献流水账；缺缺口段落；假设与研究问题脱节。

## 文献综述

- **检索策略**：布尔运算（AND/OR/NOT）、短语引号、截词符；数据库：Web of Science、Scopus、PubMed、CNKI、Google Scholar。
- 例：`("type 2 diabetes" OR T2DM) AND ("resistance training" OR "strength training") AND ("HbA1c" OR "glycemic control")`，限定 2015–2025 年、英文、RCT。
- **组织方式**：按主题（thematic）优于按时间；每个主题段先综述再评述。
- 转述（paraphrase）而非摘抄；引文要有代表性——高被引经典 + 近 3–5 年新证据。
- 用文献管理工具（Zotero/EndNote/NoteExpress）从第一天开始管理，避免最后手工排版。

## 方法（Methods）

按顺序覆盖，确保**可复现**（他人在别处能照做）：
1. **研究设计与伦理**：设计类型、伦理审批号、知情同意、预注册号（如有）。
2. **参与者**：样本来源、纳入/排除标准、样本量及功效分析依据、分组方式、流失情况。
3. **材料与测量**：量表/仪器/试剂（给出版本与信效度，如 Cronbach's α）。
4. **程序**：时间线（谁、何时、何地、做什么）、干预细节（剂量、频次、时长）、盲法与随机化。
5. **统计分析**：软件与版本、检验方法、显著性水平、效应量、缺失数据处理。

心理/医学期刊还要求遵循报告规范：**JARS**（APA 心理学）、**CONSORT**（RCT）、**STROBE**（观察性研究）、**PRISMA**（系统综述）——投稿前对照对应清单自查。

## 结果（Results）

- **先文字后图表**：先叙述主要发现，再引用图表（"如图 1 所示…"）。
- **统计报告规范（APA 7）**：
  - 均值与标准差：`M = 78.4, SD = 9.2`；中位数与四分位距：`Mdn = 72.0, IQR = [64.0, 81.0]`。
  - 检验：`t(58) = 3.24, p = .002, d = 0.84, 95% CI [3.15, 13.45]`；`F(2, 87) = 5.61, p = .005, η² = .11`；`χ²(1, N = 120) = 7.02, p = .008, V = 0.24`。
  - 斜体规则：统计符号斜体（t、F、p、d、M、SD、N、r、χ² 的字母部分）。
- 只报告与分析目的对应的结果；次要/探索性分析单独标注。
- 不显著的结果也要报告（避免发表偏倚）。

### 表格规范
- 三线表（中文期刊常用）；标题在上（APA）或在下（部分期刊按杂志要求）。
- 只保留必要的小数位（一般 2 位）；列对齐；注明单位与显著性标记（\* p < .05, \*\* p < .01, \*\*\* p < .001）。
- 表内不重复正文已有的大段文字。

### 图规范
- 每个图必须有图题（Figure caption）与编号，正文先提及。
- 坐标轴标注变量与单位；误差条说明是 SD/SE/CI；分辨率 ≥ 300 dpi；字体可读（一般 ≥ 8 pt）。
- 优先原始数据图（散点/箱线）而非仅条形图；条形图应叠加数据点。
- 制作工具：R（ggplot2）、Python（matplotlib/seaborn）、GraphPad Prism、Origin。

## 讨论（Discussion）

四步结构：
1. **重述核心发现**：第一段用 1–2 句回答研究问题（不重复结果数字）。
2. **与文献对话**：与已有研究一致/不一致之处及可能原因（引用文献）。
3. **机制与解释**：为什么会出现该结果（基于证据，谨慎推断）。
4. **局限与未来方向 + 结论**。

## 局限性（Limitations）

- 诚实列出：样本代表性、测量工具、设计缺陷（如横断面不能因果）、统计功效、推广性。
- 每一条局限给出**缓解理由或未来对策**，避免"本研究存在局限"的空话。
- 模板：`尽管本研究…（局限），但…（缓解）；未来研究可通过…加以解决。`

## 引用风格对照（四种核心格式）

以期刊论文、书籍、网页三类文献为例。**选中一种风格全稿统一**，投稿前用文献管理工具核对。

### APA 7（心理学/教育学/社会科学）
- 文中引用（作者-年份）：`(Zhang, 2020)`；直接引用加页码 `(Zhang, 2020, p. 15)`；三位及以上作者用 `(Zhang et al., 2020)`。
- 参考文献（悬挂缩进，作者姓, 名首字母）：
  - 期刊：`Zhang, L., Wang, H., & Li, Q. (2020). Title of the article. Journal Name, 12(3), 45–67. https://doi.org/xxx`
  - 书籍：`Field, A. (2018). Discovering statistics using IBM SPSS statistics (5th ed.). Sage.`
  - 网页：`Author, A. (Year, Month Day). Title of page. Site Name. URL`

### MLA 9（人文/语言文学）
- 文中引用（作者-页码）：`(Zhang 45)`。
- 参考文献（Works Cited，作者姓, 名. 标题. 刊物, 卷(期), 年, 页码.）：
  - 期刊：`Zhang, Li. "Title of the Article." Journal Name, vol. 12, no. 3, 2020, pp. 45–67.`
  - 书籍：`Field, Andy. Discovering Statistics Using IBM SPSS Statistics. 5th ed., Sage, 2018.`

### Chicago（历史/部分人文）
- **作者-年份制**（类似 APA，书名斜体，期刊文章标题加引号，文中 `(Zhang 2020)`）与**注释-参考文献制**（脚注 + Bibliography）两种。
- 脚注示例：`1. Li Zhang, "Title of the Article," Journal Name 12, no. 3 (2020): 45.`

### GB/T 7714-2015（中文期刊/学位论文国家标准）
- 顺序编码制（文中上标数字 [1]，文末按出现顺序编号）与著者-出版年制两种。
- 期刊（顺序编码制）：
  `[1] 张三, 李四, 王五. 论文标题[J]. 期刊名, 2020, 12(3): 45-67.`
- 书籍：
  `[2] 赵六. 书名[M]. 第5版. 北京: 科学出版社, 2018.`
- 文献类型标识：[J] 期刊、[M] 专著、[C] 会议录、[D] 学位论文、[R] 报告、[EB/OL] 电子资源（后接引用日期与 URL）。

## 期刊选择

| 考量 | 说明 |
|------|------|
| 匹配度 | 主题、文章类型（原创/综述）与期刊 Aim & Scope 匹配（最重要） |
| 影响力 | 影响因子、JCR 分区（Q1–Q4）、中科院分区（1–4 区） |
| 受众 | 国际（英文）vs 国内（中文）；学科侧重 |
| 开放获取 | OA 需版面费（APC），传统订阅免费投稿；警惕高价低质 OA |
| 审稿周期 | 首审 1–3 个月常见；看期刊官网公布的周期 |
| 投稿经验 | 近 2 年该刊发表的文章风格（格式、篇幅、引用密度） |

**掠夺性期刊警示**：承诺"极速录用"、版面费异常高昂、无正规同行评议、仿冒知名期刊名称者，务必查证：Check 期刊是否在 Web of Science/Scopus 收录、官网联系方式真实、检索"期刊名 + predatory"。
投稿前用期刊官网的 Author Guidelines 逐项对照格式（字数、摘要结构、参考文献风格、图表要求）。

## 应对审稿意见（Response to Reviewers）

流程：
1. 通读全部意见，分类：**可接受修改**（改数据/文字/结构）、**需补充分析**、**误解需澄清**、**无法满足**（如要求增加新实验）。
2. 逐条回复，编号一一对应：`Reviewer 1, Comment 1: … / Response: …`
3. 每条回复三要素：**复述意见 → 说明做了什么修改 → 指出修改位置（行号/页）**。
4. 能用数据/文献回应的尽量补充证据；确实无法满足的，礼貌说明理由并给出替代方案。
5. 语气：专业、对事不对人；即使意见明显错误也先肯定其关切再澄清。
6. 修改稿用修订模式或标注改动；附"修改说明"清单。
7. 若审稿人相互矛盾，按编辑要求取舍并在回复中说明。

## 常见审稿人批评与对策

| 典型批评 | 对策 |
|---------|------|
| "样本量太小/功效不足" | 补充功效分析（事前/敏感性），讨论置信区间，承认局限 |
| "缺乏对照组/无法因果" | 说明设计选择理由；用语言降级（"关联"而非"导致"） |
| "测量工具信效度不明" | 补充量表信效度证据、Cronbach's α、验证性因子分析 |
| "结果部分缺少效应量" | 补报 Cohen's d / η² / V 与 95% CI |
| "多重比较未校正" | 补 Bonferroni/FDR 校正并更新结论 |
| "引言未引用最新文献" | 检索近 3 年文献补充，并说明理论脉络 |
| "方法不可复现" | 补充细节：程序时间线、软件版本、随机化方案、缺失数据处理 |
| "讨论过度解读" | 每项解释绑定证据；增加局限与替代解释段落 |
| "图表不清/与正文不符" | 重制图表，核对数字一致性，加图注说明 |
| "英语/语言问题" | 专业润色（或建议研究者用润色服务），请母语者审读 |

## 投稿前检查清单

- [ ] 标题 ≤ 期刊字数限制，含关键词
- [ ] 结构式摘要含四要素且与正文一致
- [ ] 关键词 3–6 个，用领域标准词表
- [ ] 引言有明确的"缺口"段落
- [ ] 方法覆盖参与者/材料/程序/统计，可复现
- [ ] 结果含效应量与置信区间，不显著结果也报告
- [ ] 图表规范（三线表/图题/分辨率/单位）
- [ ] 讨论含局限与未来方向
- [ ] 全文引用风格统一（APA 7 / MLA 9 / Chicago / GB/T 7714）
- [ ] 对照期刊 Author Guidelines 与报告规范清单（CONSORT/STROBE/PRISMA/JARS）
- [ ] 数据可用性声明、利益冲突声明、伦理声明齐全
- [ ] 查重通过，无自我抄袭（避免重复发表自己已发表内容）
