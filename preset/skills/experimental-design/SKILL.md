# experimental-design

> 实验设计（Experimental Design）——从操纵、对照、随机化到样本量与功效计算，帮助 AI 代理为研究者设计出能支撑因果推断的实验方案。

## 何时使用本技能

- 研究问题涉及因果推断（"X 是否导致 Y"）。
- 需要决定采用真实验、准实验还是非实验设计。
- 需要选择被试间/被试内/混合/析因设计并权衡优缺点。
- 需要做功效分析（power analysis）确定样本量。
- 需要识别并控制混淆变量与效度威胁。

## 核心概念

- **自变量 IV**：研究者操纵（操纵变量）或分类（准自变量）的变量。
- **因变量 DV**：被测量的结果变量。
- **控制变量**：保持恒定或统计控制，防止干扰。
- **混淆变量**：与 IV 相关且能解释 DV 变化的第三变量——因果推断的头号杀手。
- **操纵**：实验与观察研究的根本区别；无操纵则无真实验。

## 因果推断三要件（Cook & Campbell）

1. 原因与结果**共变**（IV 变化时 DV 随之变化）；
2. 原因在**时间上先于**结果；
3. 排除**替代解释**（即控制混淆）。

## 设计类型总览与决策

| 设计 | 随机分配？ | 操纵？ | 因果强度 | 适用情境 |
|------|:---:|:---:|:---:|------|
| 真实验（RCT） | 是 | 是 | 强 | 可行且伦理允许时首选 |
| 准实验 | 否 | 是 | 中 | 无法随机（教育、组织、临床现实） |
| 非实验（观察/相关） | 否 | 否 | 弱 | 探索、伦理/成本限制 |

决策流程：
1. 能随机分配且伦理允许 → 真实验。
2. 能操纵但无法随机（如分班、政策）→ 准实验。
3. 无法操纵（性别、人格、患病状态）→ 观察/相关设计，明确只谈关联。

## 被试间 vs 被试内设计

| 维度 | 被试间（between-subjects） | 被试内（within-subjects） |
|------|---------------------------|---------------------------|
| 分配 | 每名被试只接受一个条件 | 每名被试接受所有条件 |
| 统计功效 | 较低（个体差异进入误差项） | 较高（个体差异被剥离） |
| 样本量需求 | 大 | 约为被试间的 1/2（节省被试） |
| 主要威胁 | 组间基线差异 | 顺序/练习/疲劳/残留效应 |
| 典型检验 | 独立样本 t 检验、单因素 ANOVA | 配对 t 检验、重复测量 ANOVA |
| 适用 | 被试内无法实现（如学习不可逆） | 条件可重复、无长期残留 |

被试内的顺序效应控制：
- **平衡设计（counterbalancing）**：条件顺序在被试间轮换；
- **拉丁方**：每种条件在各位置出现次数相等；
- 条件间**洗脱期（washout）**，或随机化顺序。

## 析因设计（Factorial）

- 同时操纵 ≥2 个自变量（因素），每个因素有 ≥2 个水平。
- 记法：2×2 表示两个因素各两个水平，共 4 个条件。
- 关注**主效应**（每个因素单独的平均效应）与**交互作用**（一个因素的效应依赖另一因素的水平）。
- 分析：双因素 ANOVA（参见 statistical-analysis 技能）。

示例 2×2：因素 A = 教学方法（传统/翻转），因素 B = 班级规模（小/大）。交互作用意味着"翻转教学的效果是否取决于班级规模"。

## 随机化、对照与盲法

### 随机分配方法
- **简单随机**：随机数表/软件逐人分配；大样本可用。
- **区组随机**：按区组大小随机，保证各阶段组间人数均衡（临床试验常用）。
- **分层随机**：先按预后因素分层再随机，保证关键变量组间平衡。

### 对照组类型
| 对照 | 做法 | 用途 |
|------|------|------|
| 空白对照 | 不接受处理 | 基线比较 |
| 安慰剂对照 | 接受无活性处理 | 排除安慰剂效应 |
| 标准对照 | 接受现行标准治疗 | 伦理学必须时（不剥夺有效治疗） |
| 自身对照 | 同一被试前后比较 | 被试内设计 |

### 盲法
- **单盲**：被试不知道分组。
- **双盲**：被试与执行者均不知道（金标准）。
- **三盲**：被试、执行者、数据分析者均不知。
- 无法盲法时：**分配隐藏**（concealment）+ 结果盲评 + 客观结局指标。

## 准实验设计（无法随机时）

| 设计 | 结构 | 适用 |
|------|------|------|
| 不等组前后测 | O1 X O2 / O1 O2 | 两群体可比较 |
| 中断时间序列 | O O O X O O O | 政策/干预的时间效应 |
| 回归断点 | 按临界值分配（如分数线） | 有明确分配规则 |
| 单组前后测 | O1 X O2 | 最弱，尽量配对照 |

准实验报告必须明确承认选择偏差的可能性，并用倾向得分匹配、双重差分等方法缓解。

## 样本量与统计功效

### 概念
- **功效 Power = 1 − β**：真实效应被检出的概率；惯例目标 0.80。
- **α**：I 类错误率（假阳性），惯例 0.05（双侧）。
- **β**：II 类错误率（假阴性）。
- **效应量**：标准化效应大小（Cohen's d、η² 等），功效分析的核心输入。

### 两组均数比较的样本量公式（独立 t 检验，双侧）
```
n（每组）= 2 × (z_{1−α/2} + z_{1−β})² / d²
```
α=0.05、power=0.80 时 z 值约为 1.96 与 0.84，即：
```
n = 2 × (1.96 + 0.84)² / d² ≈ 15.7 / d²
```
Cohen's d 惯例：小 0.20、中 0.50、大 0.80 → 每组约需 393 / 63 / 25 人。

### 相关/回归
检出中等相关（r = 0.30）需约 n ≈ 85（power=0.80，α=0.05）。

### 工具
- **G\*Power**（免费软件）：t 检验、ANOVA、回归、卡方均可，选择检验类型 → 输入效应量与 α/power → 得 n。
- **R**：`pwr` 包（`pwr.t.test`、`pwr.anova.test`、`pwr.r.test`、`pwr.chisq.test`）。
- **Python**：`statsmodels.stats.power`（`TTestIndPower`、`FTestAnovaPower`）。

```r
# R: 独立 t 检验功效分析
library(pwr)
pwr.t.test(d = 0.5, sig.level = 0.05, power = 0.80, type = "two.sample")
# 输出 n = 63.8 → 每组 64 人
```

```python
# Python: 双样本 t 检验功效
from statsmodels.stats.power import TTestIndPower
n = TTestIndPower().solve_power(effect_size=0.5, alpha=0.05, power=0.80)
print(n)  # ≈ 63.8 → 每组 64 人
```

注意：功效分析应在**收集数据前**进行并写入研究方案；事后功效分析（post-hoc）价值有限，应报告置信区间代替。

## 混淆变量的控制策略

| 策略 | 做法 | 适用 |
|------|------|------|
| 随机化 | 随机分配到条件 | 真实验首选 |
| 匹配 | 按关键变量配对后分配 | 小样本 |
| 区组 | 把混淆变量作为区组因素 | 已知混淆 |
| 统计控制 | 将混淆作为协变量（ANCOVA/回归） | 测量到的混淆 |
| 恒定化 | 保持条件一致（同一环境、程序、时段） | 实验操作层面 |

## 标准工作流程

1. 明确因果问题与 IV、DV、控制变量（写成一句话）。
2. 判断设计类型（真实验/准实验/非实验）并给出理由。
3. 选择被试间/被试内/析因，说明顺序效应或基线差异对策。
4. 确定 IV 各水平、操纵细节与操纵检验（manipulation check）。
5. 选择因变量测量工具（信效度，见 research-methodology）。
6. 做功效分析确定样本量（报告效应量来源）。
7. 制定随机化与盲法方案。
8. 列出潜在混淆与效度威胁及对策。
9. 写成实验方案，交研究者预注册或伦理审查。

## 常见误区

- ❌ 把相关设计当实验写因果结论。
- ❌ 被试内设计不做平衡，顺序效应污染结果。
- ❌ 随机分组 ≠ 随机抽样：内部效度 ≠ 外部效度。
- ❌ 样本量拍脑袋：未做功效分析，事后被审稿人质疑 power。
- ❌ 忽略操纵检验：干预无效却宣称"效应"。
- ❌ 单组前后测宣称因果。
- ❌ 事后功效分析代替事前计划。

## 检查清单

- [ ] 因果三要件均满足或明确承认局限
- [ ] IV 有明确的水平与操纵检验
- [ ] 随机分配/盲法方案已写明
- [ ] 顺序效应或基线差异已处理
- [ ] 样本量来自事前的功效分析
- [ ] 混淆变量清单与控制策略完整
