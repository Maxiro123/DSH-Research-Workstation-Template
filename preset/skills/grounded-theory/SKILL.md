# grounded-theory

## 一、何时使用扎根理论

扎根理论（Grounded Theory, GT）是一种**从数据中生成理论**的方法论：不预先检验假设，而是通过系统化的编码与持续比较，让范畴和范畴间关系从资料中"生长"出来。

适合使用的情形：
- 研究问题聚焦"过程"（如职业转型如何发生）、"互动"（如医患信任如何建立）或"策略"（如组织如何应对危机）；
- 该领域缺乏成熟理论框架，或既有理论解释力不足（"理论缺口"论证）；
- 目标是提出**新的中层理论/概念模型**而非验证假设；
- 数据以质性为主：半结构化访谈、参与观察、田野笔记、档案文献、网络文本。

不适合的情形：
- 已有明确理论假设需要检验（改用演绎设计，如问卷或假设检验）；
- 只需对数据做主题归纳（用主题分析 thematic analysis 更轻量）；
- 研究问题关注变量间的统计关联（用回归等）。

> 主题分析与扎根理论的区别：主题分析止步于"描述与组织主题"；扎根理论必须进一步完成**理论抽样、持续比较与理论生成**，产出范畴间的关系模型。

## 二、三种主要流派（动笔前先选定）

| 维度 | 经典 GT（Glaser） | 斯特劳斯 GT（Strauss & Corbin） | 建构主义 GT（Charmaz） |
|---|---|---|---|
| 认识论 | 实证主义倾向 | 实用主义/后实证 | 建构主义/诠释 |
| 理论来源 | 一切皆数据，理论"涌现" | 用"编码范式"启发分析 | 理论是研究者与参与者共同建构的 |
| 文献回顾 | **延迟**（避免污染） | 允许早期但有批判性 | 允许早期，但当作"分析资源"而非"框" |
| 编码程序 | 实质编码+理论编码，自由开放 | **开放→主轴→选择**，三步较程序化 | 初始编码→聚焦编码→理论编码，更灵活 |
| 主要概念 | 核心范畴、理论敏感性 | 编码范式、条件/行动/后果 | 情境性、反思性、被建构的意义 |
| 常见学科 | 社会学经典传统 | 护理、管理、应用研究 | 教育学、传播学、跨文化研究 |

**给 AI 助手的建议**：先确认研究者采用哪一流派（或要求其在论文中声明），因为编码程序、文献策略与"验证"话语都随之不同；不要默认混用三者的术语。

## 三、核心概念速查

| 概念 | 含义 |
|---|---|
| 编码（coding） | 给数据片段贴概念标签的系统过程 |
| 开放式编码 | 逐句/逐行初始打标签，尽量"贴数据" |
| 主轴编码 | 把范畴联系起来，建立类属关系 |
| 选择性编码 | 围绕核心范畴整合理论 |
| 持续比较 | 数据与数据、数据与范畴、范畴与范畴之间不断对照 |
| 理论抽样 | 依据"还需要什么数据完善范畴"决定下一步采样 |
| 理论饱和 | 新数据不再产生新范畴/新属性 |
| 备忘录（memo） | 分析过程中的思想记录，介于编码与写作之间 |
| 核心范畴 | 统领其他范畴的中心概念 |
| 理论敏感性 | 从数据中看见理论意涵的能力 |
| 编码范式 | Strauss 的因果条件→现象→情境→干预条件→行动策略→后果 |

## 四、标准研究流程

1. **界定研究问题**：开放式问题（"……是如何发生的？"），避免预设变量清单。
2. **初步采样与数据收集**：从目的采样开始，访谈、观察、文档并行。
3. **开放式编码**：逐行/逐事件贴标签，形成初始代码。
4. **持续比较与聚类**：合并同类代码为**范畴**，记录属性（properties）与维度（dimensions）。
5. **主轴编码**：用编码范式或"条件–行动–后果"框架连接范畴。
6. **理论抽样**：根据范畴缺口选择新的受访者/资料。
7. **选择性编码**：确定核心范畴，把其他范畴围绕它组织成理论骨架。
8. **饱和检验**：确认不再有新范畴出现后停止采样。
9. **备忘录贯穿始终**：从第一天开始写，直到成稿。
10. **撰写理论**：以核心范畴为轴，呈现范畴间关系（配图表与原始数据引文）。

```text
数据收集 ──→ 开放编码 ──→ 范畴化 ──→ 主轴编码
    ↑                                        │
    │          持续比较 / 备忘录              ↓
    └──── 理论抽样（回到田野）←─── 选择性编码 ← 理论骨架
                                        │
                                  饱和？─否→ 继续采样
                                   │
                                  是→ 撰写理论
```

## 五、编码详解

### 5.1 开放式编码（一级编码）
目标：打开数据。逐句/逐行提问："这段资料讲的是什么现象？属于什么范畴？"
- 使用**行动性/过程性**短语（"寻求同伴确认""回避冲突话题"），少用抽象名词。
- 保留参与者的本土概念（in-vivo codes），如患者说的"像被推着走"。
- 先开放后收敛：编码初期不急于合并。

### 5.2 主轴编码（二级编码）
目标：把分散范畴连接成"轴"。Strauss & Corbin 的编码范式：

```text
[因果条件] → [现象] → [情境(context)] → [干预条件] → [行动/互动策略] → [后果]
```

示例：现象="患者延迟就医"；因果条件="症状被正常化"；情境="医疗资源紧张"；策略="自我管理+观望"；后果="病情恶化时被动入院"。主轴编码产出的是**过程性模型**而非静态清单。

### 5.3 选择性编码（三级编码）
目标：确定**核心范畴**——能统摄其他所有范畴的中心概念（如"慢性病患者的'协商式依赖'"）。判断标准：
- 与其他范畴联系最多、最核心；
- 反复出现且能解释变异；
- 对理论有统领力（注意：**出现频率≠理论重要性**）。

### 5.4 编码示例

| 访谈片段（节选） | 开放式编码 | 主轴编码 | 选择性编码 |
|---|---|---|---|
| "医生只给我三分钟，我话没说完他就开药了。" | 问诊时间短；话语被打断；被动接受处方 | 情境：时间压力下的门诊互动 | 核心范畴：医患互动中的"话语权不对等" |
| "回家后我上网查，觉得药不对，又不敢停。" | 网络查证；怀疑药方；不敢停药 | 策略：谨慎服从与私下质疑 | 同上 |
| "后来我换了个大夫，他听我讲完，我才放心。" | 更换医生；被倾听；信任建立 | 后果：信任重建依赖"被倾听" | 同上 |

## 六、持续比较与理论抽样

**持续比较**是 GT 的引擎，四个层级：
1. 事件与事件比较（同一范畴内的变异）；
2. 数据与范畴比较（该数据是否属于此范畴）；
3. 范畴与范畴比较（范畴间关系是否成立）；
4. 范畴与理论比较（与文献对话，但不被其框定）。

**理论抽样**操作：写完一批编码后自问——"核心范畴在哪种情境下会变异？谁还没被访到？"据此选择下一批样本（如先访患者，再访家属、医生），直至范畴饱和。

## 七、理论饱和的判断（写论文必答）

- 操作性判断：连续 3–5 次访谈/资料单元后没有新增范畴，也没有新属性或维度；
- 范畴的内部变异已被覆盖（极端案例已纳入）；
- 范畴间关系已被反复验证且无新矛盾。

> 常见批评："声称饱和但实际只是时间用完"。论文中应写明饱和检验的证据（如最后几轮采样的编码增量记录）。

## 八、备忘录（Memo）

备忘录贯穿全程，形式自由（一段话、图表、对话），内容应为**分析性**而非描述性：
- 这个范畴为什么有意思？它与谁相关？
- 我看到了什么模式？可能的解释？
- 这与既有理论对话在哪？
- 下一步需要什么数据？

NVivo 中可为每个节点/案例写备忘录并与数据链接；GT 研究中备忘录的累积本身就是分析文档。

## 九、软件支持（NVivo 等）

| 软件 | 特点 | 适用 |
|---|---|---|
| NVivo | 节点层级、矩阵编码、模型、备忘录、查询 | 主流选择，教程多 |
| MAXQDA | 类似 NVivo，编码条带可视 | 德系习惯 |
| ATLAS.ti | 网络视图强 | 复杂关系建模 |
| RQDA / R（tidytext） | 免费、可脚本化 | 熟悉 R 的研究者 |
| Taguette / QualCoder | 免费轻量 | 小项目 |

**NVivo 标准工作流**：
1. 新建项目 → 导入转录稿/文档；
2. 建立**节点**（Node）→ 开放式编码（拖选片段到节点）；
3. 用**层级节点/文件夹**组织范畴 → 主轴编码；
4. 用**关系图/模型**连接范畴 → 选择性编码；
5. 用查询（文本搜索、编码矩阵、组查询）辅助持续比较；
6. 为节点写**备忘录**，链接案例属性；
7. 导出编码结构、矩阵与模型图用于论文。

## 十、质量评价标准

| 流派 | 标准 |
|---|---|
| Glaser（经典） | 契合（fit）、运作（work）、相关（relevance）、可修改（modifiability） |
| Strauss & Corbin | 研究过程严谨性、经验基础扎实、概念密度、过程与变异呈现 |
| Charmaz（建构主义） | 可信度（credibility）、原创性（originality）、共鸣（resonance）、有用性（usefulness） |

通用检查：编码-数据可追溯（引文可回查）、范畴有属性与维度、范畴间关系有证据支撑、饱和有据、研究者反思性（positionality）有交代、理论是"生成的"而非"套用的"。

## 十一、常见误区与陷阱

| 误区 | 正确做法 |
|---|---|
| 把主题分析当扎根理论 | GT 必须有理论抽样、持续比较与理论生成 |
| 文献回顾过早且被文献框住 | 按流派策略处理；文献作"对话对象"而非"分析框架" |
| 编码只是贴标签，范畴无关系 | 主轴/选择性编码必须建立范畴间关系 |
| 按出现频率选核心范畴 | 核心范畴看**理论统领力**与解释力 |
| 便利抽样冒充理论抽样 | 抽样决策由范畴缺口驱动并记录理由 |
| 声称饱和无证据 | 报告饱和检验的操作证据 |
| 不写备忘录 | 备忘录是分析连续性的载体 |
| 只描述不理论（数据重述） | 必须产出范畴关系模型/命题 |
| 三种流派术语混用 | 明确选定一流派并保持术语一致 |
| 访谈问题完全结构化 | 用开放式问题，允许参与者定义议题 |
