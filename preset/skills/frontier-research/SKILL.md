# frontier-research

## 何时使用本技能

- 研究中涉及预印本（arXiv/bioRxiv/SSRN）、预注册、注册报告等开放科学实践
- 需要撰写数据可用性声明、开放数据/代码仓库或可复现研究环境
- 需要判断一篇"突破性"新论文的可信度（媒体热炒、样本小、无预注册）
- 需要为期刊投稿准备开放科学要素（数据、代码、许可、声明）
- 不适用：常规的成熟方法复现（直接看方法部分即可）；已进入正式期刊的稳定文献综述

## 核心原则

开放科学的四根支柱：**预注册（先写假设再分析）、预印本（先共享再评审）、开放数据与代码（可复现）、开放获取（可阅读）**。目标不是"流程繁琐"，而是让结论经得起验证。

## 1. 预印本（Preprints）

| 平台 | 领域 | 特点 |
|---|---|---|
| arXiv | 物理、数学、CS、统计 | 最老牌，无评审、发表快 |
| bioRxiv / medRxiv | 生物 / 医学 | 需作者承诺符合伦理（如伦理审批） |
| SSRN | 社科、经济、法学 | 社科领域首选 |
| OSF Preprints | 跨学科 | 与 OSF 项目打通 |

发布预印本的好处与风险：

- ✅ 确立首发权（时间戳）、获得早期反馈、加速引用
- ⚠️ 未经同行评审，错误可能被传播——发布前至少自查 + 同事互审
- ⚠️ 多数期刊接受已发预印本的稿件（投稿前查期刊政策）；"预印本禁令"极罕见但存在
- 版本管理：修订后在平台上更新版本，并同步更新版本号（如 arXiv 的 `arXiv:2201.11903v2`）

## 2. 预注册（Preregistration）

预注册 = 在收集/分析数据之前，公开记录研究假设、样本量、变量与分析方法。

何时需要：

- 假设检验类研究（尤其是因果、治疗效应、心理/社科实验）
- 会面对"p-hacking""HARKing"质疑的研究
- 探索性分析 ≠ 预注册——探索性发现应明确标注"未预注册、需验证"

平台与模板：

| 平台 | 特点 |
|---|---|
| OSF (osf.io) | 免费、可锁定时间戳、模板丰富 |
| AsPredicted | 9 个问题式模板，评审友好 |
| ClinicalTrials.gov | 临床试验法定注册 |
| 中国临床试验注册中心 (ChiCTR) | 国内临床试验注册 |

关键点：注册后**修改方案是允许的**，但要在"偏差说明"里报告改了哪里、为什么改——预注册不是枷锁，而是透明。

## 3. 注册报告（Registered Reports）

注册报告的流程：先送审方案 → 期刊批准（in-principle acceptance, IPA）→ 再收集数据 → 无论结果如何都发表。

- 适合：验证性研究、昂贵数据、结果可能"不显著"的研究
- 好处：结果无关的发表承诺，消除发表偏倚
- 主流支持期刊：Nature Human Behaviour、Cortex、Royal Society Open Science 等（查找：Center for Open Science 的 RR 期刊列表）
- 阶段：Stage 1（方案）→ Stage 2（结果 + 方案合规说明）

## 4. 开放数据与代码

共享什么：原始数据（脱敏后）、处理脚本、分析代码、README、运行环境。

| 事项 | 推荐做法 |
|---|---|
| 数据仓库 | OSF、figshare、Zenodo、Dryad、国家科学数据平台 |
| 代码仓库 | GitHub/Gitee + 版本标签（tag）+ 归档到 Zenodo 获得 DOI |
| 许可证 | 数据 CC-BY / CC0；代码 MIT / Apache-2.0；明确写清 |
| 隐私 | 受试者数据脱敏、匿名化；涉及伦理审批的数据在声明中说明访问条件 |

```markdown
# README 模板要点
1. 研究目的与问题
2. 数据结构说明（变量字典）
3. 复现步骤：环境 → 数据 → 脚本 → 输出
4. 许可证与引用方式
5. 联系方式
```

代码要求：固定随机种子、固定依赖版本（`requirements.txt` 或 `environment.yml`）、脚本可从头到尾运行。

## 5. 可复现研究（Reproducible Research）

三级可复现性：**数据可用（可拿到）→ 结果可复现（代码跑出同样数字）→ 结论可扩展（换数据仍成立）**。

实用清单：

- [ ] 所有随机种子固定（`random.seed(42)`、`numpy.random.seed`、sklearn 的 `random_state`）
- [ ] 依赖版本固定：`pip freeze > requirements.txt` 或 conda `environment.yml`
- [ ] 分析脚本单向运行：raw data → 中间产物 → 结果，禁止手工改中间文件
- [ ] 版本管理：git 提交记录每一步；关键结果与数据文件用 Zenodo 归档
- [ ] 计算环境：复杂环境用 Docker/Singularity 容器，或提供版本输出（如 R 的 `sessionInfo()`）
- [ ] 在论文里写清"复现入口"：仓库链接 + 数据 DOI + 运行说明

## 6. 数据可用性声明（Data Availability Statement）

论文必备段落，写清"数据在哪、谁能拿、怎么拿"：

```text
# 数据可用性声明（示例一：公开数据）
本研究所用数据已匿名化处理，可在 Zenodo（DOI: 10.5281/zenodo.XXXXXXX）公开获取，
代码见 GitHub（https://github.com/xxx/xxx，v1.0.0）。

# 示例二：受限数据
由于伦理审批限制，原始数据无法公开；去标识化的汇总数据可向通讯作者申请，
访问需签订数据使用协议。

# 示例三：无新数据
本研究基于已发表的公开数据（引用来源），无新数据生成。
```

常见期刊要求：声明必须出现在稿件中，且编辑会抽查链接可用性——**投稿前逐个点击验证链接**。

## 7. 预注册模板（可直接套用）

```markdown
# 预注册方案
## 1. 研究问题与假设
- 研究问题：（一句话）
- 假设 H1/H2：（可证伪，指明方向与效应量）
## 2. 样本与数据
- 样本来源、纳入排除标准、目标样本量及计算依据（如功效分析 power analysis）
## 3. 变量与测量
- 自变量/因变量/协变量定义、量表或测量工具
## 4. 分析计划
- 主要分析（先指定主模型与主检验）
- 次要/探索性分析（单独列出，与主分析区分）
- 异常值处理、缺失数据处理、多重比较校正方法
## 5. 排除标准
- 哪些情况剔除数据、何时决定（预先写明，避免事后合理化）
## 6. 偏差说明
- 与最初方案的偏离及原因（分析后填写）
```

## 8. 开放获取（Open Access）

| 类型 | 含义 | 费用 |
|---|---|---|
| 金色 OA | 期刊出版时立即免费公开 | 常收 APC（数千美元） |
| 绿色 OA | 作者把接受稿存入机构库/预印本平台 | 免费 |
| 钻石 OA | 期刊免费发表且免费阅读 | 免费（常由学会资助） |

- 查期刊 OA 政策：`Sherpa Romeo`；查论文是否可免费获取：`Unpaywall` 浏览器插件/API
- 中国学者注意：国家自然科学基金委与中科院明确支持开放获取与公共资金论文开放共享
- 许可协议：CC BY（最开放）到 CC BY-NC-ND（限制商业与修改）；选择前看资助方与期刊要求
- 警惕掠夺性期刊（predatory journals）：以收费为目的、无真实同行评审——查 `DOAJ`、`Think.Check.Submit` 与期刊是否被主流数据库收录

## 9. 评估新颖主张（Evaluating Novel Claims）

面对一篇"颠覆性"论文或媒体头条，按此清单质疑：

| 维度 | 要问的问题 |
|---|---|
| 效应量 | 效应大得离谱？小样本大效应最可疑 |
| 样本 | 样本量多大？功效分析做过吗？样本有代表性吗？ |
| 预注册 | 是验证性还是探索性？假设是分析前还是分析后提出（HARKing）？ |
| 多重比较 | 跑了几百个检验只报显著的？是否做了校正？ |
| 可复现性 | 数据代码公开吗？第三方复现过吗？ |
| 发表渠道 | 顶级期刊同行评审？还是掠夺性期刊/预印本未经评审？ |
| 复现历史 | 类似"突破"此前失败过几次（先验概率）？ |
| 利益冲突 | 作者/资助方有商业利益吗？ |

红旗信号：只报告显著结果、p 值边缘显著但宣称突破、无数据可用性声明、媒体先于同行评审热炒、结果无法被独立小组复现。

## 常见陷阱

1. 把未预注册的探索性发现当作验证性结论报告
2. 预注册后大改分析而不在偏差说明中交代
3. 说"数据开放"但链接失效或没有许可证
4. 代码没有固定依赖与种子，声称"可复现"
5. 数据可用性声明含糊（"数据可向作者索取"却无联系方式与条件）
6. 混淆预印本与同行评审结论，引用未经评审的预印本当作定论
7. 被掠夺性期刊的"快速发表"诱惑
8. 评估新主张时忽略基率：小概率真效应的领域里，"显著结果"多数仍是假阳性

## 完成清单

- [ ] 验证性研究已预注册（OSF/AsPredicted），偏差说明已撰写
- [ ] 预印本已发布或计划发布，版本与 DOI 管理清楚
- [ ] 数据与代码已上传（仓库链接 + 数据 DOI + 许可证）
- [ ] README 含复现步骤，种子与依赖版本固定
- [ ] 数据可用性声明已写入稿件且链接可访问
- [ ] 期刊 OA 政策已核查，许可协议符合要求
- [ ] 新主张评估已逐项对照第 9 节清单
